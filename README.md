# ⚡ RA3D Nutrition — الموقع الرسمي

موقع تفاعلي فاخر لعلامة المكملات الرياضية **RA3D Nutrition**، مصمم بأعلى معايير تجربة المستخدم السينمائية وتصميم Awwwards.

![RA3D Nutrition](public/assets/mascot.png)

## ✨ المميزات الرئيسية

- ⚡ **نظام البرق التفاعلي العام (Global Lightning System):** ضربات برق ديناميكية مولدة برمجياً بشبكة معمارية تفاعلية.
- 🗿 **اسم "رَعْد" المحفور في الجدار:** نحت صخري ثلاثي الأبعاد يتوهج بقلب بلازما أحمر فائق التوهج عند ضرب الصاعقة.
- 💎 **أزرار الزجاج السائل (Liquid Glass Button System):** أزرار زجاجية سائلة مع انكسار الضوء ولمعة Meniscus سائلة فائقة الانسيابية.
- 🏎️ **أداء خارق (Smooth 60/120 FPS):** معالجة GPU مخصصة بدون Drop Frames، خطوط محلية مسبقة التحميل بدون حظر الشبكة، وتبريد معالج الرسوميات في وضع السكون.
- 🖋️ **خطوط ثمانية الأصلية:**
  - `Thmanyah Serif Display` للعناوين الرئيسية الكبرى.
  - `Thmanyah Sans` للنصوص والأزرار والواجهة.
- 📱 **متجاوب 100%:** تجربة متكاملة على جميع الشاشات والموبايل.
